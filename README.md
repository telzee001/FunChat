# FunChat
A modern web-based chat application built to explore real-world frontend and software engineering concepts.

FunChat is a WhatsApp-Web-inspired messaging application designed as a practical software engineering project.

The project begins as a frontend-focused application and progressively introduces JavaScript-driven interactions, client-side persistence, responsive design, application architecture, testing, deployment, and future backend integration.

Project status: In active development
Current phase: Welcome Page / UI Foundation
Version target: V1.0

Overview

FunChat is being developed as a practical project for learning how modern web applications are structured, designed, implemented, tested, and deployed.

Rather than attempting to reproduce WhatsApp completely, FunChat focuses on building a smaller but properly structured messaging application with a realistic user experience.

The application will eventually allow users to:

Enter through a welcome page
Create an account
Log in
Access a chat dashboard
View contacts and conversations
Select conversations
Read messages
Send messages
Search conversations
Manage basic profile information
Persist basic application data locally
Use the application across different screen sizes

The first version intentionally avoids complex production infrastructure such as real-time cross-device messaging, end-to-end encryption, voice/video calling, and production authentication systems.

Project Vision

The goal of FunChat is not simply to create another chat UI.

The project is being developed to answer a more important question:

Can a complete application be designed, structured, built, tested, debugged, documented, and deployed from the ground up?

The project therefore serves two purposes:

A functional web application
A practical software engineering learning project

Every development stage is intended to introduce concepts that are useful beyond FunChat and applicable to larger applications.
